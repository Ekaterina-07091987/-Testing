# Jest Functions — задача 2

Учебный проект с четырьмя функциями и тестами на Jest.

## Установка

```bash
npm install
```

## Запуск тестов

```bash
npm test
```

## Функции

- `sum(a, b)` — сумма чисел;
- `multiply(a, b)` — произведение чисел;
- `divide(a, b)` — деление; при делении на ноль выбрасывает ошибку;
- `isEven(n)` — проверка, является ли число чётным.
